# GraphMamba DARC 普适性实验报告

## Material Passport

- Experiment: frozen DARC universality matrix
- Status: COMPLETE
- Protocol: ETT, M→M, input=96, prediction=96/192/336/720
- Seeds: 2021, 2022, 2023
- Selection: element-weighted validation MSE; test uses the same best-validation checkpoint
- No architecture or hyperparameter changes after test inspection

## 汇总结论

- 完成配对任务：16/16；每项计划 3 个随机种子。
- Test MSE 均值获胜：13/16。
- Test MAE 均值获胜：12/16。
- 任务级平均相对变化：MSE +0.098%，MAE +0.099%（正值表示DARC改善）。
- 16个任务宏平均：MSE `0.374810 → 0.374518`（+0.078%），MAE
  `0.393722 → 0.393336`（+0.098%）。
- 48个seed级配对中，DARC取得MSE胜利32次、MAE胜利33次。
- 二项符号检验：任务级MSE胜率13/16的双侧 `p≈0.0213`；MAE胜率
  12/16的双侧 `p≈0.0768`。这说明改善方向较广，但效应幅度很小。

## 审计说明

- Baseline 与 DARC 对每个 dataset/prediction/seed 严格配对。
- DARC 固定使用 `variable_scale_residual`，未进行数据集或预测长度专属调参。
- 原始逐次记录位于 `logs/graphmamba_darc_universality/final/`。
- `runs.csv` 保存每次运行；`summary.csv` 保存配对统计。
- 正值 Δ 表示误差下降，负值如实表示退化。
- 训练与测试总用时约113.34分钟；单次记录平均用时baseline 69.29秒、
  DARC 72.39秒，端到端平均开销约+4.48%。
- 参数开销随预测长度由+1.00%（96）缓慢增加至+1.10%（720）。

## 结果解释与边界

- DARC在13/16个任务上降低平均Test MSE，说明它具有一定普适性，而非只在
  ETTh1/ETTh2-96生效。
- 但平均提升仅约0.1%，多个任务接近数值持平；因此不能表述为“大幅提升”。
- 明确失败项为ETTh1-192、ETTm1-720、ETTm2-720；其中ETTm2-720受seed
  2023的大幅波动影响尤其明显，DARC并未改善该不稳定性。
- 验证与测试MSE改善方向只在8/16个任务一致，而MAE为12/16；这表明单个
  validation split对微小结构差异的排序仍有噪声。
- 当前最严谨的论文表述是：DARC以约1.0%参数和4.5%端到端运行时间开销，
  在统一超参数下获得广泛但温和的误差下降；它尚不是稳定支配所有长度的模块。
- 下一步应研究预测长度感知的残差约束或正则化，但新结构必须重新走验证冻结
  流程，不能使用本轮测试集继续定向调参并复报为无偏最终结果。
