# GraphMamba 物理时间归一化双路径：阶段一非 Solar 分析

## 结论

当前候选结构 **未通过预注册阶段一门控，应停止沿用这一具体实现**。Solar 虽按要求延期，但其结果已经不可能改变总体门控结论：在已完成的 6 组比较中，候选仅取得 2 胜；即使 Solar 的 2 组全部获胜，最终也至多为 4/8，仍低于要求的 6/8。

这一结论否定的是“近期原生分辨率路径 + 全历史逐小时均值池化周期路径”这一具体实现，并不否定日周期信息本身。训练集周期审计仍表明各数据集存在稳定的日周期，只是当前表示方式不能跨采样频率稳定转化为预测收益。

## 实验边界

- 数据集：ETTh1、ETTm1、Weather；Solar 延期且不参与统计。
- 预测长度：192、720。
- 随机种子：2021。
- B0：`GraphMambaRecent`，近期 96 点、独立共享双 Patch。
- B1：`GraphMambaPeriodNorm`，近期 96 点局部分支 + 全 336 点按物理小时归一化的周期分支。
- 指标均来自验证集，`test_after_train=0`；没有读取 v2 测试集指标。

## 聚合结果

- MSE 胜场：B1 为 2/6；计入尚未运行的两组 Solar 后，理论上最多 4/8。
- 六组宏平均 MSE：B0 为 0.870075，B1 为 0.899390；B1 劣化 3.37%。
- 六组宏平均 MAE：B0 为 0.571663，B1 为 0.567575；B1 改善 0.72%。
- 总训练时间：B0 为 1342.155 秒，B1 为 856.976 秒；B1/B0 为 0.639。
- 逐任务时间比宏平均为 0.741。
- 参数量比根据数据集和预测长度为 0.379–0.563，候选明显小于 B0，不存在依靠扩容获益的问题。

## 预注册门控判断

| 门槛 | 当前证据 | 判断 |
|---|---|---|
| 至少 6/8 个 MSE 胜场 | 已完成 2/6；即使 Solar 全胜也仅 4/8 | **确定失败** |
| 宏平均 MSE 至少改善 0.5% | 非 Solar 六组劣化 3.37% | 当前失败；完整值因 Solar 缺失不可计算 |
| 任一数据集两预测长度平均劣化不超过 1% | ETTh1 劣化 1.48%，ETTm1 劣化 13.78% | **确定失败** |
| 宏平均 MAE 不恶化 | 非 Solar 六组改善 0.72% | 当前通过 |
| 参数增长不超过 5% | 参数量为 B0 的 37.9%–56.3% | 通过 |
| 运行时间不超过 1.5× | 非 Solar 总时间比 0.639 | 通过 |

总体门控为 **失败**。胜场和数据集最坏退化两项已经在数学上无法由 Solar 结果挽回，因此停止 Solar 不影响候选结构的淘汰结论，也不应进入后续图尺度或 CMRHM 组合实验。

## 结果解释

1. **Weather 的收益是真实且一致的局部证据。** 两个预测长度的 MSE 分别改善 4.53% 和 6.77%，MAE也同步改善，说明物理时间周期路径在某些高频、强日周期数据上确有价值。
2. **该收益不能跨数据集泛化。** ETTh1 在没有降采样的情况下仍小幅退化，说明问题不只来自平均池化；ETTm1 的显著退化则表明把 15 分钟序列压缩为小时均值后，周期分支可能损失了对预测有用的日内细粒度变化。
3. **效率提升与精度损失来自同一结构变化。** 候选把 B0 的 144 个 Patch token 降为 76/55/52 个，因此参数和时间显著下降，但 ETT 上的精度也下降。不能把加速本身当作主假设成立的证据。
4. **“周期存在”不等于“均值池化周期路径有效”。** 周期审计支持日周期作为建模先验；当前实验反驳的是用固定逐小时均值池化和统一融合方式实现这一先验的普适性。

## 后续方向

- 不对该候选做结果驱动的小修小补，也不进入图尺度和 CMRHM 组合消融。
- 保留 Weather 结果作为机制线索，但若继续研究，应重新提出独立、可预注册的新结构假设，例如保留相位与日内细粒度信息的周期采样，而不是在当前候选上针对 ETT 调参。
- Solar 的已完成 3 个 epoch 仅为中断过程数据，不是可比较的最终结果；以后如恢复，应从冻结命令重新执行完整 B0/B1 配对，并单独记录高维图分支的运行成本。
