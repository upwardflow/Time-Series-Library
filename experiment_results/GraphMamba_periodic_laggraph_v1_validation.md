# GraphMamba 周期主干 × LagGraph：验证门控

## 协议

- 基线：通过两种子门控的 `periodic_aligned + adapter-only`；
- 候选：在局部/完整周期 patch 投影后加入零初始化 LagGraph 残差；
- ETTh1-192、ETTh2-192，seed 2021，validation-only；未访问测试集；
- 共享参数初始化和零门预测已验证严格相同。

## 结果

| 任务 | 周期基线 MSE / MAE | + LagGraph MSE / MAE | MSE / MAE 改善 |
|---|---|---|---|
| ETTh1-192 | 0.988814 / 0.652796 | 0.989477 / 0.652642 | -0.067% / +0.024% |
| ETTh2-192 | 0.272637 / 0.351920 | 0.272613 / 0.351591 | +0.009% / +0.093% |

宏平均 MSE 改善约 `-0.029%`，MAE 改善约 `+0.058%`。LagGraph 参数量从 824,327 增至 828,554（+4,227，约 +0.51%），总训练时长 ETTh1 从 33.7 秒增至 94.6 秒、ETTh2 从 31.0 秒增至 75.5 秒。

## 学习诊断

- ETTh1 局部/周期 lag gate 绝对均值：0.0286 / 0.0159；
- ETTh2：0.0141 / 0.0067；
- 三个频带权重都仍接近均匀（约 0.32–0.35）。

模块确实获得梯度，但周期分支门尤其小，频带也没有形成稳定选择。结合精度与约 2.4–2.8 倍训练时长，当前集成判定 no-go：代码保留为显式消融，`use_lag_graph=0` 继续为默认；不追加种子、参数搜索或测试集实验。
