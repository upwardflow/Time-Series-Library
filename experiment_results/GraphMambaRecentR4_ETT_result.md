# GraphMambaRecentR4 全 ETT 测试结果

更新时间：2026-08-26

## 实验协议

- 模型：冻结的 `GraphMambaRecentR4`，使用近期 96 点、fine patch、双向 Mamba，关闭分解与图分支。
- 数据集：ETTh1、ETTh2、ETTm1、ETTm2。
- 预测长度：96、192、336、720。
- 随机种子：2021、2022、2023。
- checkpoint：仅由验证 MSE 选择；12 个严格兼容的 Phase B/C R4 checkpoint 复用，其余 36 个重新训练。
- 测试策略：48 个 checkpoint 各执行一次 `is_training=0` 测试；测试结果不参与后续结构或超参数选择。
- 完整性：48/48 验证与 48/48 测试记录成功，所有指标有限、返回码为 0，无缺失、重复或额外单元。

## 结果解释

- 短预测稳定：96/192 长度的大多数单元 seed 标准差很低；三个 seed 的 16 单元宏观 MSE 为 0.385211、0.384017、0.379790。
- 长预测是主要瓶颈：ETTh1-720 的 MSE 标准差为 0.047815，ETTm2-336 为 0.021777，ETTh2-720 为 0.017744。
- 在已有且配置基本匹配的 24 个 ETTm1/ETTm2 R0 历史测试单元上，R4 在 ETTm1 的 MSE/MAE 分别改善 1.695%/1.540%，但在 ETTm2 分别退化 3.477%/2.355%。旧对照未声明当前的 `element_weighted_v1` 指标版本，因此该对照只作描述性解释。
- R4 在预测长度 96/720 时分别使用 684,512/4,518,992 个参数，相对匹配 R0 减少 31.369%/33.635%。

## 结论边界

R4 是更轻量、结构更干净且适合后续短期—长期潜在状态交互研究的近期骨架，但不是所有 ETT 场景上的普遍更优模型。后续交互模块应重点改善 ETTm2-336/720 与 ETTh1-720，同时保持 ETTm1 和短预测长度的现有稳定性。本测试结果已锁定为报告用途，不用于修改后续交互结构、控制组或验证门槛。
