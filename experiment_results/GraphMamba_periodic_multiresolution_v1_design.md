# GraphMamba 周期多分辨率 V1：设计冻结记录

## 假设

ETTh1/ETTh2 的训练段移动平均残差均显示 24 步为最强稳定周期。因此 V1 不再使用无物理依据的 `4/2` 双尺度，而使用：

- 周期内局部尺度：patch 4、stride 2；
- 完整周期尺度：patch 24、stride 12。

每个尺度沿自己的真实时间顺序调用同一套 Mamba 参数，调用之间重置状态。两尺度只有在 patch 覆盖的原始时间区间重叠时才能交换状态。

## 模块

1. **软周期置信度**：在每个输入样本、每个变量上，联合 24 步附近频谱能量与 lag-24 自相关。只读输入窗口，不使用标签。
2. **尺度条件适配器**：以 `patch_len/P`、`stride/P` 为尺度描述，产生输入仿射调制；输出层零初始化。
3. **共享独立扫描**：局部和周期 token 分别调用同一个 Mamba encoder，禁止跨尺度伪状态连续。
4. **物理时间对齐交换**：用两个 patch 区间的真实重叠长度构造固定稀疏语义矩阵；交换门为零初始化并由周期置信度调制。
5. **置信度路由**：局部/周期状态的相对权重由周期置信度控制；路由增益从零开始，所以初始不偏向任一尺度。

## 隔离与消融

- LagGraph 在 V1 选择期间强制关闭。
- `adapter/alignment/router` 均可分别关闭。
- 先比较同一周期 patch 几何下的 plain 与完整 V1，再与历史 joint/independent 基线比较。
- 只使用验证集；通过前不运行测试集。

## 预注册门槛

- 完整 V1 相对 periodic-plain：ETTh1-192、ETTh2-192 MSE 同方向，宏平均至少改善 0.5%，MAE 不明显恶化；
- 若未通过，按 `adapter → alignment → router` 梯度/学习状态诊断做一次结构性修正，不进行无边界网格调参；
- 修正后仍未通过则停止该版本，不接入 LagGraph。
