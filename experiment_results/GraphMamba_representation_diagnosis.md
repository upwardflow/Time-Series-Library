# GraphMamba 主干表示诊断与几何融合验证

## 诊断结论

本轮复用六个 seed-2021 GraphMamba baseline checkpoint，仅分析 validation，未训练诊断器、未访问 test。

- 长短尺度表示余弦相似度随任务变化明显（0.276–0.873），并非稳定冗余来源。
- 移除任一尺度通常使 MSE 上升，但 ETTm2-336 移除尺度反而略有改善，进一步说明尺度关系缺乏跨任务一致性。
- 时间分支与图分支余弦相似度稳定为强负值（-0.955 至 -0.984）。
- 融合表示范数仅为两分支范数和的 9.3%–15.0%，说明两个分支发生强抵消。
- 单独使用任一分支的 MSE 均明显变差，表明抵消本身包含有效互补，而非可以直接删除的冗余。

将图表示拆成相对于时间表示的平行与正交分量，用 validation 前半区拟合两个线性系数、后半区独立检验，六任务均得到正收益：0.394%、0.303%、2.036%、0.322%、0.737%、1.998%。因此该几何方向具备可检验依据。

## 唯一候选：Geometry-Aware Fusion

候选仅对图分支的平行/正交分量按变量和长短尺度进行缩放：

1. `g_parallel = proj_t(g)`；
2. `g_orthogonal = g - g_parallel`；
3. `z = t + a_parallel * g_parallel + a_orthogonal * g_orthogonal`。

系数以 baseline 等价值初始化，总计仅 28 个参数；不增加网络、损失或预测头，也不与 DARC 叠加。

## 判定

GF 比此前预测头候选更稳定，并验证了分支几何是一个真实现象，但效果仍未达到预注册的 1% 实质改善门槛。因此本轮判定为“有研究信号，但不足以成为当前有效创新点”：不进入 test，不继续增加细粒度门控，不做系数或学习率搜索。

下一阶段应离开融合系数微调，优先研究为何图分支训练为时间分支的近反向表示，以及能否在图信息进入主干之前形成互补表征。若没有新的机制假设和独立证据，不再增加模块。
