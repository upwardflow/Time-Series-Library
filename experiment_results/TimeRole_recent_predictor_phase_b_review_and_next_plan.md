Phase B 的 36 个验证单元全部有效。R1、R2、R4 通过冻结的六项准入门槛；R3、R5 因 MSE 不劣于 R0 的任务数不足 4/6 而淘汰。由于 Phase C 最多接收两个简化候选，本报告建议 **R4 作为综合首选、R2 作为效率前沿候选进入后续确认，R1 保留为精度锚点和回退方案**。

该推荐仍是单 seed 筛选结论，不是最终替换结论。Phase C 前必须先完成冻结任务书要求的 Recent-only 对照，确认 TimeRole 的远期修正带来真实净收益，而不仅是校正张量非零。

### 选择 R4 的理由

- 宏 MSE 改善 0.761%，5/6 个任务不劣于 R0，最坏单元只退化 0.211%。
- 相比 R1，宏 MSE 差距约为 R0 的 0.156%，低于任务书在候选接近时强调的 0.2% 小差异范围。
- R4 删除 Graph，结构比 R1 更简单，并获得略高的参数、延迟和训练显存下降。
- 三个数据域的平均 MSE 均改善，没有跨域系统性退化。

### 选择 R2 的理由

- 宏 MSE/MAE 分别改善 0.642%/0.120%，5/6 个任务不劣于 R0。
- 参数、训练峰值显存和推理峰值显存分别下降约 65.0%、64.8% 和 49.9%，是通过精度门槛候选中的资源前沿。
- 风险集中在 ETTm1-96：该单元 MSE 退化 1.495%，必须通过多 seed Phase C 检查是否稳定存在。

### R1 为何暂不占用两个名额之一

R1 是 Phase B 的最佳精度和最稳健候选，应保留为回退基线。但最多两个名额下，R4 提供了与 R1 接近的精度和更简单的无 Graph 结构，R2 则提供明显不同的高效率前沿。选择 R4+R2 能覆盖两种非冗余的简化方向；若后续 Recent-only 对照否定其中之一，R1 是首选替补。

## 下一步执行计划

### Step 1：Phase B2 Recent-only 对照（下一组操作）

先运行任务书第一阶段强制要求的 R0、R1、R4、R5 Recent-only，并为拟入围的 R2 补齐对应控制：

- 组合：3 数据集 × 2 horizons × 5 变体 × seed 2021，共 30 个验证任务。
- 唯一模型差异：关闭 TimeRole 远期修正，近期预测器结构和所有训练超参数保持一致。
- 精确命令：

```bash
.venv/bin/python -u scripts/run_timerole_recent_simplification.py \
  --stage phase_b --role recent --variants R0 R1 R2 R4 R5 \
  --gpu 0 --timeout-seconds 3600
```

- 门禁：比较每个结构的 TimeRole 与 Recent-only 配对 MSE；若 R4 或 R2 的 TimeRole 宏平均收益消失，则不得进入 Phase C，优先启用 R1 回退检查。
- 仍然只使用验证集，禁止测试集访问；失败后停止且不自动重试。

### Step 2：确认 Phase C 名单

结合 B2 后按以下顺序决策：

1. R4 与 R2 均保留 TimeRole 净收益：确认两者进入 Phase C。
2. 其中一个失去净收益：用 R1 替补，但仅在 R1 的 TimeRole 对照通过时。
3. 两者及 R1 均失去净收益：停止简化并保留 R0。

### Step 3：Phase C 三 seed 确认

- 比较 R0 与最终两个候选。
- 矩阵：3 数据集 × 2 horizons × seeds 2021/2022/2023 × 3 模型，共 54 个 TimeRole 结果。
- 严格兼容的 Phase B seed-2021 记录可复用；因此预计新增 36 个 TimeRole 训练。
- 对应 Recent-only 也需覆盖相同 18 个 dataset–horizon–seed 单元；B2 seed-2021 可复用，预计新增 36 个 Recent-only 训练。
- 在生成队列前扩展 runner 的 `phase_c` stage，并加入严格的 source/config/data-order 哈希复用审核。

最终替换必须满足任务书的 11/18 MSE 不劣、宏 MSE/MAE ≤0.5%退化、参数/延迟/显存下降门槛、每数据集覆盖和 TimeRole 对 Recent-only 至少 12/18 胜场。Phase C 审核完成前不启动 Phase D 或访问测试集。

## 统计与解释限制

- Phase B 每个任务只有一个 seed，不能估计随机波动、置信区间或统计显著性。
- 本轮比较了五个简化候选；虽然候选与门槛已冻结，选取表现最好的候选仍存在筛选偏差，必须由 Phase C 独立 seeds 缓解。
- 宏平均掩盖局部异质性：尤其 R2 在 ETTm1-96 的退化，不能被其他任务改善直接抵消。
- correction RMS 非零只证明分支产生数值输出，不证明它改善预测；Recent-only 配对是强制证据。
