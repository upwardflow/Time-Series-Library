# GraphMamba 周期多分辨率 V2：验证结论

## 严格配对

V2 与 V1 adapter-only 参数、初始化、patch 几何完全一致；唯一变化是完整周期分支的 adapter 残差乘以样本×变量的 24 步周期置信度。alignment/router 均关闭，未访问测试集。

| 任务 | V1 adapter MSE / MAE | V2 confidence-adapter MSE / MAE | V2 相对变化 |
|---|---|---|---|
| ETTh1-192 | 0.988814 / 0.652796 | 0.988788 / 0.653235 | MSE +0.003%，MAE -0.067% |
| ETTh2-192 | 0.272637 / 0.351920 | 0.271447 / 0.355305 | MSE +0.436%，MAE -0.962% |

宏平均 MSE 改善约 0.219%，低于 0.5% 门槛，且两个任务 MAE 都恶化。V2 判定为 no-go，不设为推荐路径，也不继续调置信度公式或阈值。

当前推荐路径恢复为 V1 adapter-only：周期驱动 patch 几何、各尺度独立共享 Mamba、尺度描述条件适配；物理时间交换、输出路由和置信度适配均保留为已归档消融，默认关闭。
