# GraphMamba 周期多分辨率 V1：验证与自我修正记录

## 协议

- 任务：ETTh1-192、ETTh2-192，seed 2021；
- 只训练并读取训练/验证划分，全部 `test_after_train=0`；
- 所有 V1 消融具有相同周期 patch 几何、相同参数集合和严格相同初始输出；
- `plain → adapter → adapter+alignment → full` 为顺序消融。

## 结果

| 版本 | ETTh1 MSE / MAE | ETTh2 MSE / MAE | 解释 |
|---|---|---|---|
| periodic-plain | 0.995264 / 0.654875 | 0.276115 / 0.353272 | 周期分段、独立共享扫描 |
| + scale adapter | **0.988814 / 0.652796** | **0.272637 / 0.351920** | 两任务最佳 MSE |
| + aligned exchange | 0.990024 / **0.652280** | 0.273342 / 0.352564 | MSE 在两任务均退化 |
| + confidence router | 0.990001 / 0.652457 | 0.273322 / 0.352581 | 相对上一行近似无变化 |

尺度适配相对 periodic-plain 的 MSE 改善为 ETTh1 `0.648%`、ETTh2 `1.260%`，宏平均 `0.954%`；相对历史 joint 基线分别改善 `1.309%`、`0.964%`。ETT 配置参数量为 824,327，历史 joint 为 1,891,575，减少约 56.4%，差异主要来自预测头接收 56 而非 144 个 patch token。

## checkpoint 诊断

- 验证输入的 24 步周期置信度具有明显变量差异，ETTh1 变量均值约 0.36–0.78，ETTh2 约 0.23–0.71；
- scale adapter 的绝对调制幅度约 0.17–0.45，确实被使用；
- aligned exchange 门约 0.02–0.033，非零但较弱；
- router gain 仅 0.052–0.087，实际周期权重约 0.501–0.514，几乎没有形成动态选择。

## 自我修正决定

1. V1 推荐路径改为 `periodic_use_adapter=1, alignment=0, router=0`。
2. 保留 alignment/router 代码作为负结果消融，不作为默认结构。
3. V2 只做一个受诊断支持的变化：周期分支的 adapter 残差乘以样本×变量周期置信度；局部分支保持不变。该变化直接实现弱周期回退，并与 V1 adapter-only 严格配对。
4. 不访问测试集；先完成第二种子复核，再考虑把通过的 V1 backbone 接入 LagGraph。

## 第二随机种子复核

| 任务/种子 | periodic-plain MSE / MAE | adapter-only MSE / MAE | MSE 改善 |
|---|---|---|---:|
| ETTh1 / 2021 | 0.995264 / 0.654875 | 0.988814 / 0.652796 | +0.648% |
| ETTh2 / 2021 | 0.276115 / 0.353272 | 0.272637 / 0.351920 | +1.260% |
| ETTh1 / 2022 | 0.994912 / 0.654000 | 0.992667 / 0.652672 | +0.226% |
| ETTh2 / 2022 | 0.270797 / 0.352624 | 0.269931 / 0.351743 | +0.320% |

四个配对 MSE、MAE 均同方向改善；四配对平均 MSE 改善约 **0.613%**。虽然 seed 2022 的效应较小，说明仍需更多数据集/种子确认，但已通过当前 validation gate。自动策略在已验证的 ETTh1/ETTh2 上采用 `periodic_aligned + adapter-only`；其他数据集在获得训练周期证据前回退到物理安全的 `independent_shared`。`joint` 仅保留为显式历史对照。
