# TIRGE 在 ETTm1/ETTm2-720 上相反表现的诊断

## 范围

本诊断只读取训练集、validation loader、已有 GraphMamba baseline 与 TIRGE checkpoint；不训练模型、不访问 test。目标是解释 TIRGE 在 ETTm2-720 改善 1.399%，却在 ETTm1-720 退化 1.443% 的原因。

## 1. 误差差异是系统性的

TIRGE 在 ETTm1 的四个预测区间全部退化：

| 预测区间 | MSE变化 |
|---|---:|
| 1–180 | -1.472% |
| 181–360 | -1.754% |
| 361–540 | -0.986% |
| 541–720 | -1.614% |

ETTm2 四个区间则全部改善：

| 预测区间 | MSE变化 |
|---|---:|
| 1–180 | +0.795% |
| 181–360 | +1.432% |
| 361–540 | +1.111% |
| 541–720 | +1.897% |

因此相反结果不是某个远期区间的偶然异常。

变量层面，ETTm1 除 LUFL（+1.401%）外几乎全部退化，OT 最严重（-5.783%）；ETTm2 的主要收益来自 HULL（+3.383%）、MULL（+1.966%）和 LUFL（+1.743%），OT基本持平（+0.246%）。

## 2. 两数据集的统计结构不同

| 指标 | ETTm1 | ETTm2 |
|---|---:|---:|
| 距离相关非对角均值 | 0.381 | 0.458 |
| Pearson有符号非对角均值 | 0.310 | 0.163 |
| 标准化一阶差分绝对均值 | 0.125 | 0.096 |
| 最低5%频率功率占比 | 0.937 | 0.961 |
| 日周期频带功率占比 | 0.115 | 0.026 |
| 平均谱熵 | 0.377 | 0.350 |

ETTm1 的 HUFL/MUFL 具有很强日周期能量（0.308/0.349），而 ETTm2 更低频、更平滑；ETTm2 变量间距离相关更强，但线性有符号相关更弱，提示更多非线性或异号依赖。

## 3. 未训练替换时的创新图响应

将 baseline 权重保持不变，只把图输入从原 token 换成 `T(x)-x`：

| 指标 | ETTm1 | ETTm2 |
|---|---:|---:|
| 创新/原token范数 | 1.010 | 1.088 |
| 创新图/原图输出范数 | 0.718 | 0.195 |
| 创新图与时间表示余弦 | 0.813 | 0.276 |
| 创新融合范数比例 | 0.954 | 0.896 |

这说明初始 GraphMamba 图混合器对两种创新分布的响应完全不同：ETTm1 的创新被强烈传递且与时间表示同向；ETTm2 的创新图贡献则被显著压缩。

## 4. 训练后模型绕过了“专业化”约束

真正训练完成的 TIRGE checkpoint 中：

| 指标 | ETTm1 | ETTm2 |
|---|---:|---:|
| 图输出与时间表示余弦 | -0.978 | -0.973 |
| 融合范数比例 | 0.102 | 0.113 |
| 创新/原token范数 | 1.058 | 1.174 |

两者都重新回到与 baseline 相同的“时间/图近反向、强抵消”状态。因此 `G(T(x)-x)` 并没有真正让图分支成为独立的残差编码器；网络可通过共同调整 encoder、graph mixer 和 head 恢复原来的抵消解。

ETTm2 与 baseline 的有效邻接变化更大（Frobenius 0.481，ETTm1 为 0.189）。最大变化是 OT→LULL 权重从 0.390 降至 0.089；同时若干指向 LUFL 的边增强。该重组与 HULL/MULL/LUFL 的改善一致，但目前只是相关证据，不能证明因果。

## 5. 判定

相反结果最合理的解释是：

1. ETTm1 具有更强日周期和更高短期变化，`T(x)-x` 中仍含大量可预测周期信息；统一送入图模块会重复处理时间信息，并伤害多数变量及 OT。
2. ETTm2 更低频、更平滑，且变量关系更强但线性符号一致性更弱；其训练过程能够通过更大幅度重组图邻接，从创新表示中改善 HULL/MULL/LUFL。
3. 但训练后两个模型都恢复为强抵消解，说明单纯更换图输入不足以解决分支非专门化问题。

## 6. 下一候选是否获准

当前诊断形成了一个可证伪假设：图分支应只接收“跨变量、时间上不可由单变量周期解释”的创新，而不是未经约束的 `T(x)-x`。不过实现它需要明确的去时间结构操作（例如沿变量维的残差化），并验证不会人为删除有用的 ETTm1 周期信息。

因此本阶段不立即实现新候选。下一步应先做一个只读上界实验：在已有表示上，将创新量投影掉每个变量自身的时间主成分，再测量剩余跨变量创新的图可预测性以及与误差改善的关系。只有该上界在 ETTm1 和 ETTm2 均为正，才允许编码器修改。

## 7. 去时间跨变量创新上界结果

按照上述要求完成拆分 validation 上界：前 169 个 batch 仅拟合每变量一个线性系数，后 169 个 batch 独立评估；checkpoint保持只读。

| 数据集 | 原始创新图上界 | 去时间跨变量创新上界 |
|---|---:|---:|
| ETTm1-720 | +0.121% | +0.347% |
| ETTm2-720 | +0.383% | +1.388% |

去除每个变量创新中与自身输入 token 平行的成分后，两数据集上界均提高，证明方向合理；ETTm2 的 HULL、MUFL、MULL、OT分别获得3.156%、2.026%、1.015%、1.564%的上界改善。ETTm1只有OT达到1.360%，其余多数变量低于1%，MULL还轻微退化0.005%。

两数据集简单平均上界约0.868%，且ETTm1整体仅0.347%，未满足预注册的“两数据集均改善且平均达到1%量级”要求。判定：不授权模型实现。该结果可作为未来机制线索，但不足以支持继续在当前图分支上堆叠投影或门控。
