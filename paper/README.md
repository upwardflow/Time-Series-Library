# TimeRole 论文目录

本目录以一份中文主稿为唯一正文入口，其余文件按“投稿资产、质量核验、参考资料、历史修订”分层保存。

## 当前投稿资产

- `TimeRole_中文主稿.md`：当前唯一中文主稿，已包含摘要、引言、相关工作、方法、实验与结论。
- `TimeRole_中文主稿_预览版.docx`：由当前主稿生成的预览文件。
- `TimeRole_references.bib`：主稿使用的18条参考文献。
- `TimeRole_定稿自审与主张证据表.md`：当前术语账本、主张—证据边界和投稿前清单。
- `TimeRole_补充材料候选.md`：尚待扩展的补充材料入口。

## 子目录

- `picture/`：论文图片、可编辑绘图源文件及投稿用矢量导出文件。
- `tables/`：由冻结实验记录生成的正文表格源文件。
- `quality_checks/`：仍可复用的引用与格式核验记录。
- `references/`：样刊 PDF、相关工作地图和版式研究笔记，不属于正文。
- `archive/revision_history/`：已经完成使命的写作计划、审稿报告和中间修订版，仅用于追溯。

## 术语约定

完整模型统一使用 `TimeRole`。其近期路径称为“图增强状态空间近期预测器”，远期路径称为“压缩历史修正分支”。旧名 `GraphMamba–CMRHM`、代码标识 `GraphMambaCMRHM` 以及缩写 `CMRHM`/`CCHM` 只允许出现在历史归档、旧实验路径和兼容入口中。

代码中的正式入口为 `models/TimeRole.py`，新实验使用 `--model TimeRole` 与 `--timerole_*` 参数。旧模型名和 `--cmrhm_*` 参数仍作为兼容别名保留，以便读取既有命令与检查点。

## 使用原则

后续正文修改只写入当前主稿；完成一轮审查后，将审查记录放入 `archive/revision_history/`，不要再创建并列正文版本。实验数字应先在结果归档中冻结，再同步到主稿和主张—证据表。
