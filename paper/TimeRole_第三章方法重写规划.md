# TimeRole 第三章方法重写规划

## 1. 本轮结论

第三章应保留用户提出的“两部分”组织思想，但不建议使用“短期预测”和“长期预测”作为小节名称。在时间序列领域，这两个术语通常指预测区间长短，而 TimeRole 的两条路径实际按**历史观测距预测起点的远近**分工：近期窗口生成完整基础预测，远期历史仅生成条件修正。因此，建议统一命名为：

1. **图增强状态空间近期预测器（RGSP）**，负责近期窗口基础预测；
2. **远期历史修正器（DHC）**，负责远期历史条件修正。

实验命名固定为：**Recent96 = RGSP（仅输入最后96点）**，**TimeRole = RGSP + DHC（读取完整336点，其中前240点由 DHC 处理）**。Recent96 是实验变体名，不作为 RGSP 的模块名称；TimeXer 等迁移实验中的基础模型统一称为“近期窗口主干”。

这一命名既保留两部分主线，也与 models/TimeRole.py 的实际前向过程一致。

## 2. 范文依据与可借鉴流程

本规划核对了 paper/references 中七篇 Neurocomputing 正式论文的方法章节。

| 范文 | 方法组织中可借鉴的部分 | 对 TimeRole 的启示 |
|---|---|---|
| Wrinkles in Time | 先用总览图解释双分支及输出重组，再按两条分支展开 | 与 TimeRole 的职责分化和输出相加最接近 |
| AweHF | Symbols/problem formulation → overview → modules → objective | 先固定数学任务，再进入架构细节 |
| ms-Mamba | Overview figure 后严格按前向顺序写 embedding、核心层、projection、objective | 模块顺序应对应真实执行顺序 |
| S-Mamba | 总览文字和算法框先给完整流程，随后逐层展开 | 复杂主干必须先提供全局地图；TimeRole 已有架构图，无需再加算法框 |
| DiM | 在 architecture overview 中给归一化和整体映射式 | 共享归一化可并入总览，不必成为独立主模块 |
| MPFGSN | Problem definition → framework → modules → complexity → loss/training | 方法末尾统一收束训练与复杂度 |
| DualNet | 先声明双路径部件，再分别给设计、公式与作用 | 两条路径可以并列展开，但不应把修正路径写成第二个完整预测器 |

范文的共同流程是：**任务定义 → 总览图与整体映射 → 按前向过程展开模块 → 输出重组 → 训练目标/复杂度**。TimeRole 应采用这一流程，而不是沿用现稿中“总览段落很快进入细节公式”的写法。

## 3. 一句话方法论证

TimeRole 将近期窗口建模为完整基础预测，将压缩远期历史建模为对同一近期状态的有界条件修正，从而在不扩大高成本近期主干输入的情况下利用更长历史。

## 4. 建议章节结构

### 3.1 问题定义与历史职责划分

**本节任务：** 定义预测任务、输入划分和两段历史的不同职责，使读者先理解 TimeRole 解决的不是普通多分支融合问题。

**段落安排：**

1. 定义多变量长期预测的输入、输出和映射，统一 $L$、$H$、$N$ 等符号。
2. 将完整历史写成 $\mathbf X_t=[\mathbf X_t^d;\mathbf X_t^r]$，定义 $L_d$、$L_r$ 及二者的时间位置。
3. 明确职责分配：$\mathbf X_t^r$ 负责基础预测，$\mathbf X_t^d$ 只在近期状态条件下修正该预测。此处用肯定式陈述设计，不展开重复防御。

**保留公式：** 预测任务定义、历史划分公式。

**删减事项：** 不在本节介绍 Mamba、图学习或池化细节；不使用“短期预测/长期预测”描述两条路径。

### 3.2 TimeRole 总体框架

**本节任务：** 用图1和少量公式建立完整前向地图，回答“输入如何流到最终预测”。

**段落安排：**

1. 指向图1，概括输入划分、近期基础预测、远期条件修正和输出重组四个阶段。
2. 定义以近期窗口统计量为参照的共享归一化。解释其功能：把远期观测表示为相对于当前局部水平和尺度的偏移；仅在此处引用 RevIN 相关来源。
3. 给出整体映射：

   \[
   \widehat{\mathbf Y}^{b}_t=F_{\theta}(\mathbf X_t^r),\qquad
   \Delta\mathbf Y_t=C_{\phi}(\widetilde{\mathbf X}_t^r,\widetilde{\mathbf X}_t^d),\qquad
   \widehat{\mathbf Y}_t=\widehat{\mathbf Y}^{b}_t+\Delta\mathbf Y_t.
   \]

4. 用一句章节导航说明 3.3、3.4 和 3.5 的内容。

**控制原则：** 本节只保留均值/标准差、两段归一化和整体映射，不提前解释 patch、图邻接、配对解码或复杂度。

### 3.3 近期窗口基础预测：图增强状态空间近期预测器（RGSP）

**本节任务：** 说明近期路径如何从原分辨率近期窗口生成完整基础预测。建议保留三个三级小节，但压缩重复解释。

#### 3.3.1 分解与双尺度表示

- 动机：近期窗口同时包含平滑演化与局部波动，需要分别处理趋势与季节/残差成分。
- 前向过程：移动平均分解 → 趋势线性投影 → 两个 patch 网格 → patch token、位置编码和变量嵌入。
- 必须说明：两个尺度覆盖同一近期窗口；它们是两套采样网格，不是需要连续扫描的两段序列。
- 公式：分解式、趋势投影、patch 数量、token 构造。
- 引用：移动平均分解和 patching 的来源只在首次使用处给出。

#### 3.3.2 图增强双向状态空间编码

- 动机：时间状态和变量关系是基础预测所需的两类互补信息。
- 时间分支：两个尺度使用共享的双向 Mamba 参数，但分别执行扫描并重置尺度间状态。
- 图分支：训练区间距离相关图与全局学习图融合；明确学习图对样本共享，不能称为动态邻接。
- 融合：默认模型采用时间状态与图状态直接相加；自适应门控仅属于消融，不进入主模型叙述。
- 公式：双向编码的紧凑层公式、邻接融合式、图传播式。
- 不写：通用 SSM 从连续到离散的完整推导；S-Mamba/ms-Mamba 范文已表明此类背景更适合放在 preliminaries 或引用解决。

#### 3.3.3 基础预测重建

- 将两个尺度的融合状态拼接并经预测头得到季节预测。
- 与趋势投影相加得到归一化空间中的基础预测。
- 用近期均值与标准差恢复原尺度，输出 $\widehat{\mathbf Y}^{b}_t$。
- 本节结尾只需确认该输出承担完整预测职责，不重复讨论远期路径“不做什么”。

### 3.4 远期历史条件修正：远期历史修正器（DHC）

**本节任务：** 这是 TimeRole 的核心差异化部分，应比现稿更集中地呈现“条件化—配对差分—有界注入”链条。

#### 3.4.1 压缩历史上下文

- 使用近期参照归一化远期历史。
- 以不重叠平均池化将 $L_d$ 个观测压缩为 $K_m=L_d/r$ 个记忆 token。
- 将近期窗口和压缩历史分别投影为 $\mathbf h_n^r$ 与 $\mathbf h_n^m$。
- 明确该分支逐变量处理，不执行额外图传播。
- 公式：平均池化、近期/历史状态投影。

#### 3.4.2 配对解码与有界修正

- 在同一近期状态和同一共享解码器下计算 $D(\mathbf h_n^r)$ 与 $D(\mathbf h_n^r+\mathbf h_n^m)$。
- 以两者差值定义远期历史引起的条件变化 $\boldsymbol\delta_n$。
- 通过 $g_n=\tanh(a_n)$ 调节每个变量的方向和相对强度，再乘近期标准差恢复量纲。
- 给出最终输出公式 $\widehat{\mathbf Y}=\widehat{\mathbf Y}^{b}+\Delta\mathbf Y$。
- 作用表述应写为“使远期历史以条件修正的形式进入输出”，不要写成“已证明每个部件不可替代”。

### 3.5 训练目标与计算开销

**本节任务：** 简洁收束训练方式和引入远期修正分支的增量成本。

1. 给出端到端 MSE 目标；优化器、学习率、训练轮数和早停放在实验设置，不在此重复。
2. 给出修正分支的新增参数量 $P_{\mathrm{HC}}$。
3. 给出池化和线性映射的增量计算复杂度，并明确这是相对 Recent96 的额外开销，不是 TimeRole 总复杂度。
4. 用一句话连接到实验中的效率对照，不在方法节提前报告结果。

## 5. 图1修改建议

现有图1已经包含总览、近期路径和远期路径三个面板，结构满足本轮重写，不需要新增方法图。建议正式重写前完成以下小改：

1. 图和正文统一保留 RGSP/DHC；在摘要和正文各自首次出现时采用“中文全称（缩写）”，随后使用缩写。
2. Panel c 将修正公式显式画成

   \[
   \Delta\mathbf Y=\tanh(\mathbf a)\odot\boldsymbol\sigma\odot
   [D(\mathbf h^r+\mathbf h^m)-D(\mathbf h^r)],
   \]

   减少当前减号、门控和尺度恢复之间的视觉歧义。
3. 保留 Panel a 中从近期窗口到远期分支的条件虚线，但将其标注为 recent-state conditioning，而不是含糊的 condition。
4. 图中学习图应写为 globally learned graph 或 shared learned graph，避免被理解为样本动态图。

## 8. 建议篇幅与写作顺序

- 建议方法部分约占 **3.5–4.5 个双栏页面**；以读者可复现为准，不按固定字数机械扩写。
- 正式成稿顺序：先写 3.3 和 3.4 的纯前向设计，再写 3.1/3.2 的框架叙述，最后写 3.5 和图注。
- 语言顺序：每个模块采用“目的 → 输入与操作 → 输出与全局作用”，不在每段末尾重复防御性边界。
- 实现超参数、数据集专用设置和训练协议统一留在第4章实验设置。
