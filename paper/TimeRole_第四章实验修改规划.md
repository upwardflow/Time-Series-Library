# TimeRole 第四章实验重写规划（固定 R0）

## 1. 规划结论

第四章应围绕固定的 R0 近期预测模型展开，不再承担近期主干选择任务。R0 负责根据最近96点生成完整基础预测，第四章需要验证的是：DHC 是否能够稳定利用前240点远期历史、其条件修正设计为何有效、模型实际利用了什么历史信息，以及这种历史利用是否具有合理成本。

参考 `paper/references` 中七篇 Neurocomputing 正式论文，建议采用以下组合式写作结构：

- 以 **ms-Mamba** 的“定量结果—消融—定性分析—效率”作为总体骨架；
- 以 **Wrinkles in Time** 和 **MPFGSN** 的聚焦式消融组织每个设计问题；
- 以 **AweHF** 的研究问题导航提高长实验章的可读性；
- 以 **DualNet** 的路径分解可视化展示基础预测、修正和最终输出；
- 以 **S-Mamba** 的输入长度与效率实验支撑“使用更长历史”的核心命题；
- 以 **DiM** 的专门机制对照和输入长度分析补足公平性与敏感性。

第四章不应继续以七张连续表格为主体。建议最终形成“6张主文表 + 3张结果图”的结构，并将完整逐种子结果、扩展机制对照和可选近邻实验放入补充材料。

## 2. 固定模型与术语

### 2.1 投稿模型

- **R0 / RGSP**：固定近期预测器，包含趋势—季节分解、粗细双尺度 patch、参数共享的双向 Mamba 和变量图传播。
- **Recent96**：严格的 `TimeRole w/o DHC`，输入样本仍按336点对齐，但 RGSP 只读取最后96点。
- **TimeRole**：固定 R0 加 DHC；最后96点由 RGSP 处理，前240点由 DHC 压缩并形成条件修正。
- **Raw336**：固定近期主干直接处理完整336点，用于比较“职责分化”与“扩大高成本主干输入”。

第四章不讨论近期预测器简化或模型选择。R0 内部组件只在第三章作为已冻结近期预测流程说明，不作为第四章的主要创新主张。

### 2.2 核心论证句

> 在固定 R0 近期预测器和统一训练协议下，TimeRole 通过 DHC 从压缩远期历史形成条件修正，在保持接近 Recent96 资源成本的同时获得稳定的预测收益；历史干预、设计消融和输出分解进一步说明该收益依赖与当前样本匹配的远期信息。

## 3. 建议的第四章主体结构

**拟采用的正文标题：4. Experiments**

章节开头用一段话给出五个研究问题。研究问题只用于导航，正文标题保持 Neurocomputing 常见的描述式标题。

- **RQ1：总体性能。** TimeRole 与代表性长期预测模型相比是否具有竞争力？
- **RQ2：职责分化有效性。** 在相同 R0 下，加入 DHC 是否稳定优于 Recent96？
- **RQ3：设计合理性。** 近期条件、配对差分、变量级注入和压缩策略分别起什么作用？
- **RQ4：历史使用机制。** 模型是否依赖与当前样本匹配的远期历史，修正具体改变了什么？
- **RQ5：实用性。** 更长历史带来的收益需要多少参数、延迟和显存成本，能否迁移到另一类主干？

### 4.3 历史职责分化的有效性（RQ2）

#### 4.3.1 TimeRole 与 Recent96 的严格配对

这是第四章最重要的消融，不应继续写成普通基线对照。

- 先说明 Recent96 即 `TimeRole w/o DHC`，两者共享 R0、近期输入、优化设置、随机种子和选点规则。

- 结论限定为固定 R0 与 ETTm1/ETTm2 协议下的稳定远期历史收益。

当前表只显示 MSE，需要补充 MAE 两列，使正文中的24/24 MAE胜场在主文内可以直接核验。

#### 4.3.2 与直接长输入的对照

本小节比较三种历史使用方式：

- Recent96：只使用近期窗口；
- Raw336：让高成本 R0 直接读取全部336点；
- TimeRole：R0读取96点，DHC压缩处理前240点。

本节先比较验证精度，再把参数、延迟和显存留到4.7集中解释。这样能够回答：TimeRole 的收益是否只是“读取更多点”，以及职责分化与直接扩大主干输入的差别。

现有证据仅覆盖 ETTm1/ETTm2、H=96/720、seed 2021，因此它属于受控诊断，不与三种子测试主表合并。

其中，`HistoryOnly` 和 `SeparateNorm` 只是规划阶段的工作标签，正式名称需在数学定义和代码开关冻结后统一：

- `HistoryOnly` 检查远期修正是否需要当前近期状态条件；必须在实现前明确数学形式，不能临时改变多个因素。
- `SeparateNorm` 用远期历史自身统计量替代近期参照，检查共享近期坐标系是否发挥作用。
- 不设置 `DHC-only / w/o RGSP`，因为 DHC 输出的是条件修正量，不是独立完整预测器，该变体不保持预测任务语义。

现有 Concat、NoDiff 和 GlobalGate 结果表明完整 TimeRole 并非每个任务都最优，因此正文应写成“完整设计获得更均衡的总体结果”，而不是“所有部件在每个数据集都不可替代”。

#### 4.4.3 历史范围与压缩分辨率敏感性

这是参考 S-Mamba、MPFGSN、Wrinkles in Time 和 DiM 后最需要补充的一组实验。所有实验使用验证集，默认配置336/96/16不因结果而改变。

建议三个单因素组：

1. 总历史长度：\(L\in\{192,336,720,960\}\)，固定 \(L_r=96\)、pool=16；
2. 近期长度：\(L_r\in\{48,96,192\}\)，固定 \(L=336\)、pool=16；
3. 池化宽度：pool \(\in\{8,16,24\}\)，固定 \(L=336\)、\(L_r=96\)。

采用 ETTm1、ETTm2 和 Weather，预测跨度96/720，三随机种子；去除默认配置的重复运行。结果用三面板折线图报告 MSE 均值和标准差阴影，不为每个网格点堆叠显著性检验。

该实验的目的不是重新选择默认超参数，而是回答稳定区间、收益饱和点和失败边界。

#### 4.4.4 变量级修正行为

使用已有变量系数和冻结模型输出，报告 DHC 在变量维和预测步上的实际修正行为：

- 各数据集 \(g_n=\tanh(a_n)\) 的分布；
- 每个变量的平均绝对修正幅值；
- 修正幅值与 Recent96 误差降低之间的关系。

推荐使用一张双面板图：左侧为变量系数/修正幅值分布，右侧为“修正幅值—误差变化”散点。该图用于描述模型行为，不直接写成因果解释。

3. 不允许根据最终图形美观程度手工挑选。

### 4.6 跨骨干迁移（RQ5）

保留 TimeXer+DHC 作为迁移证据，但降低篇幅和主张强度。

- 表格同时给出 MSE 与 MAE；当前正文只给 MSE，必须补齐。
- 明确两种设置均读取同一336点样本，TimeXer 主干均只处理最后96点，唯一差异是是否由 DHC 使用前240点。
- 四个正式测试任务均改善，宏平均 MSE/MAE 改善可作为迁移示例。
- 由于目前是单种子、两个 ETT 分钟级数据集，结论写为“提供跨骨干迁移证据”，不写“可用于任意骨干”。

PatchTST 上的 IRPA--DHC 同预算对照建议放入补充材料：它适合说明 DHC 与检索式历史利用之间的精度—效率差异，但会分散固定 R0 的正文主线。

### 4.7 精度—效率折中与讨论（RQ5）

#### 4.7.1 精度与资源成本

保留 Recent96、Raw336、TimeRole 三方资源对照，统一报告验证 MSE、参数量、每批推理延迟和峰值显存。正文分两个方向解释：TimeRole 相对 Recent96 以小幅资源增量换取历史收益；相对 Raw336 则显著降低主干直接处理长输入的成本。

如果资源测量的预热与重复次数已齐全，可增加精度—延迟散点作为补充图；若测量协议尚不完整，则先保留表格，不画可能夸大微小差异的散点。

#### 4.7.2 讨论与适用边界

讨论拆为三段：

1. **核心发现：** 历史职责分化在固定 R0 下带来稳定远期历史收益；
2. **机制与数据差异：** 样本匹配历史的重要性较一致，但顺序敏感性和最佳条件化形式具有数据依赖性；
3. **当前边界：** 固定近期—远期分割、固定池化宽度、跨样本共享变量系数，以及迁移实验覆盖范围有限。

## 6. 图表写作与排版规范

- 表格标题置于表上方，图标题置于图下方；标题只说明协议和符号，不在标题中写长段结果讨论。
- 表格采用 `booktabs`，不使用竖线；MSE/MAE 标注 \(\downarrow\)，延迟和显存写明单位。
- 同一表内统一小数位数；排名依据未舍入数值，并在表注说明。
- 主表使用粗体/下划线表示最佳与次优；消融表只强调完整 TimeRole 和关键对照，避免满表粗体。
- 每张图只回答一个主要问题。多面板必须共享一个上位结论，而不是把无关结果拼在一起。
- 误差条使用三随机种子的样本标准差；单种子诊断图不得画伪误差条。
- validation 与 test 必须在标题或图注中显式标明。
- 样本可视化必须记录数据集、变量索引、窗口起点、预测跨度和选择规则。
